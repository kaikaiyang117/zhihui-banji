# 凯凯小兵 Agent 代理清单

> 这份清单记录 Agent 的已完成能力和后续迭代任务。当前仅开放四个单条低风险写入，且必须经过权限、预览、确认、备份和审计；删除、批量和敏感写入不开放。

当前验收基线：schema v21、123 项隔离 SQLite 后端测试通过；前端构建和 UI 冒烟通过。真实数据、真实微信 iLink 长时间运行、断线重连和移动设备兼容性仍以 [`发布检查清单.md`](发布检查清单.md) 为准。

## 当前基础能力

- [x] 自有 Agent 运行时，不依赖 OpenClaw
- [x] DeepSeek / OpenAI-compatible 模型配置
- [x] 网页端和微信 iLink 两个入口
- [x] 学生搜索、班级人数、学生档案、学生时间线只读工具
- [x] 批量学生字段查询和学生分布聚合
- [x] 考勤、成绩、待办、家校沟通只读工具
- [x] 常见班级问题的确定性意图路由
- [x] Agent Harness 意图归一化、计划校验和一次性空结果纠错
- [x] 工具白名单、参数校验和调用审计
- [x] 微信渠道默认禁止敏感学生档案字段
- [x] 网页端 SSE 流式回答
- [x] 网页端 Markdown 安全渲染

## 第一阶段：基础可靠性补齐

- [x] 流式输出：网页端逐段显示模型回答
- [x] 常用查询工具：学生、考勤、成绩、待办、家校沟通
- [x] 高频问题确定性路由，降低模型漏调用工具的概率
- [x] “所有学生/学生家长/家长职业/全班分布”使用批量查询或聚合，不逐个读取学生档案
- [x] 模型超时和流式错误提示
- [x] 微信和网页入口使用统一 Agent 工具层
- [x] 工具调用失败处理、一次自动重试和重复失败熔断
- [x] 建立 Agent 问题回归样例集
  - 固定回归由 `server/tests/integration/agent*.test.ts` 执行，夹具位于 `server/tests/fixtures/`

## 第二阶段：会话和体验增强

- [x] 网页刷新后恢复当前会话历史
  - 增加会话消息读取接口
  - 保持网页和微信会话相互隔离
- [x] 会话过长时自动总结和上下文压缩
  - 保留关键事实、已调用工具结果和用户偏好
  - 控制模型上下文长度和成本
- [x] Agent 工作状态展示
  - 结构化规划步骤和当前状态
  - 正在查询考勤/成绩/待办
  - 工具调用失败原因
- [x] 模型调用可靠性增强
  - 超时重试
  - 限次退避
  - 错误 JSON 修复
  - 不可恢复时的降级回答
- [x] 网页端会话管理
  - 新建会话
  - 重命名会话
  - 删除会话
  - 会话列表
- [x] 模型与工具使用统计
  - 请求次数
  - 调用耗时
  - 工具调用次数
  - 失败率和 Token 用量（模型支持时）

## 第三阶段：安全写入和 Agent 评测

- [x] 可控的数据写入工具
  - 创建待办
  - 记录家校沟通
  - 保存考勤
  - 记录行为积分
- [x] 写入确认状态机
  - 先生成操作预览
  - 用户明确确认后执行
  - 确认内容与实际参数绑定
  - 确认超时自动失效
- [x] 写入安全措施
  - 网页和微信分别配置操作权限
  - 写入前自动备份
  - 完整操作审计
  - 支持撤销或人工恢复
- [x] 敏感数据分级
  - 普通班级信息
  - 学生档案信息
  - 家庭住址、电话等敏感字段
  - 微信渠道和网页端分别授权
- [x] Agent 评测体系
  - 工具选择正确率
  - 查询结果准确率
  - 意图识别回归测试
  - 敏感信息泄露测试
  - 微信和网页结果一致性测试
  - 写入确认和越权测试
- [x] 发布前 Agent 回归报告
  - 固定问题集自动运行
  - 记录模型、工具、答案和审计结果
  - 关键失败案例进入下一轮测试集

## 推荐执行顺序

1. 后续新增工具或模型供应商时，先扩展固定回归样例和能力矩阵。
2. 写入工具继续保持单条、低风险、确认后执行；删除、批量和敏感字段写入不开放。
3. 多模态、多账号、群聊和 MCP 仍属于预留方向，不作为当前工作包的隐性范围。

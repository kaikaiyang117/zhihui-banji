# 移动端适配记录

> 目标：手机端（375–640px）和常见平板尺寸访问时，界面不形变、可正常操作。

## 方案：iOS Tab Bar 模式

侧栏在手机端下移至底部，变为水平固定导航栏，符合 Apple HIG 移动端规范。

## 任务拆分

- [x] **断点系统** — `≤640px`（手机）、`641–900px`（平板/小窗）、`901–1200px`（桌面）三档响应式
- [x] **侧栏→底部 Tab Bar**（≤640px）
  - 固定底部，`flex-direction: row`，高度约 56px
  - 仅显示图标 + 短标签，隐藏 header/footer/分组标题
  - 安全区域适配（`padding-bottom: env(safe-area-inset-bottom)`）
- [x] **顶栏精简**（≤640px）— 顶部工作台切换与搜索分行，避免窄屏拥挤
- [x] **主内容区**（≤640px）
  - `padding: 14px`，`max-width: 100%`
  - 页面标题缩小至 20px
  - 卡片 `padding: 16px`，`border-radius: 12px`
- [x] **概览卡片** — 手机端 2 列网格，`gap: 8px`
- [x] **搜索框/输入框** — 手机端 `width: 100%`，输入字号避免系统自动缩放
- [x] **表格** — `table-wrap` 横向滚动，添加右侧渐变遮罩提示可滚动
- [x] **弹窗** — 手机端底部 Sheet，表单单列排布并适配安全区域
- [x] **侧栏收窄**（641–900px）— 仅显示图标（64px 宽）
- [x] **图表** — 手机端高度调整为 250px
- [x] **座位表** — 手机端横向滚动，单元格最小 32px
- [x] **touch 增强** — 按钮和主要输入控件最小点击区域 44px

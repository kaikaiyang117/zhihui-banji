## 1. 快速上手

### 1.0 使用桌面安装包

当前版本可从 [GitHub Releases v1.0.4](https://github.com/aitia0718/workbench/releases/tag/v1.0.4) 下载：

- Windows：下载 `MeimeiWorkbench-Setup-Windows-x64.exe`，双击安装。
- Apple Silicon Mac：下载 `MeimeiWorkbench-macOS-arm64.dmg`。
- Intel Mac：下载 `MeimeiWorkbench-macOS-x86_64.dmg`。

macOS 打开 DMG 后将应用拖入“应用程序”文件夹。当前安装包未配置代码签名证书，系统出现安全提示属于预期现象；只从项目 Release 页面下载，并确认文件名和 SHA-256 校验值后再运行。

### 1.1 启动工作台

**macOS**：双击 `启动工作台.command` 或在终端执行：
```bash
./启动工作台.command
```

**Windows**：双击 `启动工作台.bat`

启动后程序会自动打开本机工作台页面。默认开启局域网访问，电脑、手机和平板连接同一 Wi-Fi 即可使用。进入工作台后点击右上角“手机访问”，用手机或平板相机扫描二维码完成设备配对。

默认端口为 5000；如果被其他程序占用，程序会自动切换到可用端口。配对二维码仅可使用一次并在 5 分钟后失效，请只让可信设备扫描，不要将端口映射到公网。配对后的设备默认授权 90 天，重启工作台不会自动退出；可以在电脑端“手机访问”窗口中查看设备、单独撤权或全部撤权，移动端也可点击顶部退出按钮。

### 1.2 检查与安装更新

点击右上角“更新”按钮即可检查 GitHub 上的最新版本。发现新版本后，桌面安装包支持“下载并安装”：程序会下载对应系统的安装包，校验 `SHA-256` 后启动安装器。Windows 会进入安装程序，macOS 会打开 DMG；学生数据、备份和知识库保存在独立的用户数据目录，不会因更新被覆盖。

更新开始前会自动创建数据库备份。如果下载、校验或安装失败，可以在更新窗口中重试；macOS 更新助手会在新应用无法启动时恢复旧版本。

应用内更新只在桌面安装包中执行，开发模式点击“安装更新”会被拒绝。更新使用 GitHub Release 的对应平台安装包，并在校验失败时删除下载文件，不会覆盖用户数据。

### 1.3 界面布局

```
┌─────────────────────────────────────────────┐
│  🏫 教师工作台  │  👤 个人工作台             │  ← 顶部 Tab 切换
├────────┬────────────────────────────────────┤
│ 概览   │                                    │
│ 学生管理│        主内容区                    │
│ 教学管理│     (工作表 / 图表 / 数据表)       │
│ 班级事务│                                    │
│ 日志   │                                    │
├────────┴────────────────────────────────────┤
```

- **左侧**：导航菜单，按模块分组
- **右侧**：主内容区，显示当前模块的数据和操作
- **顶部班级按钮**：显示当前班级和学期，可切换工作范围或进入班级管理

### 1.4 班级与学期

教师工作台的数据都归属于明确的班级和学期。点击顶部的“班级 · 学期”按钮可切换工作范围；切换后，学生、统计、事件、待办、考勤、成绩、班级任务、座位和值日等页面会一起刷新。个人工作台的数据不随班级切换。

点击“管理班级、学期与在班学生”可以：

- 新建或修改班级和学期。
- 将已有学生加入当前班级，或标记为转出、毕业。
- 把在读学生转入另一个使用中的班级与学期。
- 结转到新学期：复制在读名单和考勤规则，不复制历史事件、成绩、待办等业务结果。
- 归档学期。归档后的内容可以查看和导出，但不能继续添加、修改或删除。

首次从旧版本升级时，系统会自动建立“默认班级”和“默认学期”，并把原有数据无损归入该范围；之后可在管理窗口中修改名称。

### 1.5 通用操作

| 操作 | 方式 |
|------|------|
| 添加记录 | 点击页面右上角带颜色的按钮（如 `📋 添加考勤`） |
| 删除记录 | 点击删除按钮后移入回收站，普通删除不会立即清除数据库记录 |
| 恢复记录 | 进入“回收站与审计”，找到记录后点击“恢复” |
| 查看全部 | 数据表支持滚动浏览 |
| 搜索过滤 | 输入关键字后按 Enter 实时过滤（支持的表页） |
| 导出 Excel | 点击 `📥 导出Excel` 按钮，下载当前班级和学期的数据 |
| 刷新数据 | 操作后数据自动刷新，无需手动 F5 |

## 2. 教师工作台

### 2.1 今日工作台

进入教师工作台后默认打开“今日工作台”。首页优先展示今天真正需要处理的行动，而不只是统计数字：

- **行动摘要** — 已逾期、今天、未来 7 天和复查日期已到的学生；点击数字卡进入已经筛选好的目标页面。
- **行动队列** — 每个工作项可直接“完成”“延期”或“处理”。完成时必须填写结果；延期会预填延后一周的截止日期，仍可手动修改。
- **考勤规则命中** — 展示待处理的异常学生和规则原因，并可进入对应工作项。
- **材料收集进度** — 展示已提交人数和完成比例，点击后直接定位到对应班级任务。
- **需要复查的学生** — 仅展示复查日期已经到期的进行中关注事项，可进入学生详情或关注处理页。
- **今日班级概况、最近动态和快捷操作** — 保留人数、出勤、最新事件以及快速记录事件、沟通、关注和考勤入口。

首页数字和提醒中心使用同一套统计口径。完成、延期或重新打开事项后，返回首页即可看到更新后的数字；系统不会使用浏览器缓存中的旧统计。

### 2.2 学生管理

#### 2.2.1 学生信息

管理当前班级和学期的在读学生基础档案（学号、姓名、性别、出生年月、民族、家庭住址、两组监护人信息、是否住校、特长、班级任职、备注，共 16 个字段）。

| 操作 | 说明 |
|------|------|
| `⬆️ 导入Excel` | 先检查预览，再确认导入/更新学生信息，按**学号**去重合并 |
| `📋 模板下载` | 下载标准导入模板（含列名与示例行） |
| `📥 导出Excel` | 导出当前班级和学期的在读学生数据 |
| 搜索框 | 按学号或姓名模糊搜索 |
| 删除 | 将学生移入回收站；学生及其关联业务记录暂时隐藏，但不会丢失 |

**导入规则**：点击“检查文件”后，系统只解析 Excel，不会立即修改数据库；确认预览结果后才提交。学号为唯一标识，模板中已有学号则更新基础档案并加入当前班级/学期，新学号则新增并加入当前范围。缺少学号、姓名或文件内重复学号的记录会被跳过并提示。

#### 2.2.2 特殊学生档案

记录需要特别关注的学生（如学习、行为或情绪状态）。点击“处理与复查”可记录多次进展、调整状态和下次复查日期，并填写阶段结论；关闭时必须明确完成或取消关联工作项。

#### 2.2.3 评语管理

管理学生的学期评语、毕业评语、日常评语。支持草稿/已完成/已发送三种状态。

#### 2.2.4 提醒中心

提醒中心是教师工作台中所有“下一步行动”的统一入口。除了手工新建工作项，学生事件跟进、家校沟通回访、关注复查、考勤规则命中、班级任务和值日安排也会自动进入这里；同一来源重复触发不会生成重复提醒。

- 顶部数字卡可筛选待处理、已逾期、今天、未来 7 天、已完成、已取消和全部。
- 可按事项、学生或备注搜索，并在列表视图和日历视图间切换。
- 工作项包含关联学生、来源、负责人、优先级、计划日期、截止日期和备注。
- 点击“完成”必须填写处理结果；取消时必须填写取消原因。已关闭项目可以重新打开。
- 编辑工作项可调整计划、延期或更改负责人；点击来源名称可回到对应事件、沟通、关注、考勤规则、班级任务或值日记录。
- 完成由事件、沟通或关注产生的工作项时，来源状态和处理结论会自动回写；重新打开工作项也会恢复来源为继续跟进状态。

从今日工作台点击“完成”或“延期”时，提醒中心会自动筛选对应时间范围并打开该事项。编辑弹窗支持键盘 Tab 导航，按 Escape 可关闭并把焦点返回原按钮。

#### 2.2.5 学生当前状态

进入学生详情后，页面顶部会先汇总当前风险及原因、未完成行动、最近变化和阶段结论，再显示完整成长时间线。成绩、积分和健康图表同时提供文字摘要，便于在手机小屏、图表加载失败或使用辅助技术时理解数据。

### 2.3 教学管理

#### 2.3.1 考勤管理

考勤页面按“日期 + 场景”完成全班点名。场景包括**常规到校、早自习、上午、下午、晚自习**，状态包括**出勤、迟到、请假、早退、缺勤**。

- 切换日期和场景后，系统读取该场次已保存的记录；尚未记录的学生默认显示为出勤。
- 迟到、请假、早退和缺勤可填写异常原因；迟到可记录到校时间，早退可记录离校时间；每名学生还可填写独立备注。
- 批量备注可应用到全班或仅当前异常学生。点击“全员到校”可快速重置本场次状态。
- 保存后系统自动检查已启用规则。迟到、请假、缺勤次数和连续缺勤达到阈值时，会为对应学生生成一个不重复的跟进工作项。
- 在提醒中心完成跟进并填写处理结果后，规则命中显示为“已处理”，结果同时进入学生时间线。条件解除后提醒自动解除；之后再次达到条件时会重开原工作项，不会制造重复事项。
- 规则卡片可查看启停状态、适用场景、最近执行时间、命中学生、处理状态和最近执行历史；“立即检查”用于手工补充检查。
- 统计区可按日期范围和场景筛选，展示状态总数、学生统计、异常名单、按月和按 ISO 周次汇总。出勤率口径为：`(出勤 + 迟到 + 早退) / 总记录`，请假和缺勤不计入出勤。
- `导出明细`输出逐条考勤记录，`导出汇总`按日期范围生成汇总 Excel。

#### 2.3.2 成绩跟踪

成绩页面按当前班级和学期管理考试、科目、导入批次、统计和异常跟进，不再限定固定科目或固定考试名称。

**第一次使用：**

1. 在“成绩配置”中添加科目，可填写满分并调整启用状态。
2. 添加考试，填写考试名称和日期，并选择这次考试应包含的科目。
3. 配置会随学期结转复制到新学期，历史考试和历史成绩不会被复制。

**导入成绩：**

- 支持长表（每行一个学生的一科成绩）和宽表（每行一个学生、多个科目列）。系统按学号识别学生。
- 选择文件后只进行预览，不立即写入数据库。预览会显示有效、错误、新增、更新和跳过数量，并标出未知学号、无效分数等错误。
- 已存在的同一学生、考试和科目记录可选择“更新”或“跳过”。错误行不会被提交；点击确认时系统会再次校验全部有效行，任一提交行失效时整批回滚。
- 分数可以填写数字，也可以标记为“缺考”或“免考”。未出现在文件中的应考科目显示为“未录入”。

**统计口径：**

- 缺考、免考和未录入都不会按 0 分计入科目平均分。
- 只有应考科目全部为正常分数的学生才计算总分、班级排名和分层；不完整成绩会明确显示缺少的科目。
- A/B/C 层按完整总分排名的前 25%、中间 50%、后 25% 划分。
- 总分变化和排名变化以该学生前一次具有完整成绩的考试为对照。

**异常跟进：**

- 可以创建“总分下降”或“单科下降”规则，并设置阈值和优先级。
- 规则命中后只生成一个统一工作项。到提醒中心填写处理结果并完成后，命中状态变为“已处理”，结果进入学生时间线。
- 后续成绩恢复时命中会解除；之后再次达到条件时复用并重开原工作项，不重复制造提醒。

**导出：**选择考试后导出单次考试汇总，缺考、免考和未录入会保留文字状态，不会导出为 0 分。

#### 2.3.3 行为积分

每周记录学生行为积分（8周），生成积分排行榜和走势图。

**页面内容：**
- **积分排行榜** — 前十名学生按总分降序
- **积分走势图** — TOP5 学生的每周积分折线图
- **积分明细表** — 全量数据展示

**派生计算**：月合计（W1-W8 总和）、班级排名（按总分降序）

### 2.4 班级事务

#### 2.4.1 座位表

可视化展示班级座位布局。座位表中包含学生姓名和特殊标记（讲台、前门、后门、过道）。座位编辑需通过对话让系统辅助修改。

#### 2.4.2 班级任务与材料收集

班级任务用于一次性布置事项并逐人收集结果。新建任务时可以选择常用模板、设置截止日期、材料名称、说明和参与学生；模板可以保存任务类型、材料名称、说明和默认截止天数。

- 任务列表显示进行中、待开始、逾期或已完成状态，以及已提交人数和完成比例。
- 每名学生可以维护“未提交、已提交、免交”、备注和提交时间；可以上传材料附件，附件先完成安全写入再登记数据库，失败不会产生伪成功记录。
- “催办”只执行应用内记录，会增加对应学生的催办次数；不会自动发送微信消息。
- 任务未收齐时点击“完成任务”必须填写完成结果，并明确确认缺交名单；系统会保存例外关闭人数。
- 班级任务会自动进入提醒中心。提醒中心或来源页面更新工作项时，任务也会同步更新；从工作台完成未收齐任务同样会被拦截。

#### 2.4.3 值日安排

值日支持按单日查看和按周查看。手动添加时输入日期、区域和学生；同一学生同一天被安排到不同区域会被拒绝并提示冲突。

- “轮换规则”可以配置区域、日期范围和学生顺序，先预览本周安排，再确认批量生成。
- 生成前会检查同一区域已有其他学生和同一学生跨区域冲突；存在冲突时不会部分写入。
- 点击“待完成”标记完成时必须填写完成记录；记录会同步到提醒中心和对应值日来源。

#### 2.4.4 家校沟通记录

记录每次家校沟通的详细信息：日期、学生、沟通方式（电话/微信/面谈/家访/短信）、原因、内容摘要、家长反馈、双方约定和后续回访。点击“处理”可追加多次进展、安排下一次联系、填写回访结论并同步关联工作项。

#### 2.4.5 谈心记录

记录与学生的谈心过程：日期、学生姓名、谈心原因、地点、内容摘要、学生状态、后续计划、下次跟进时间。

#### 2.4.6 班会记录

班会组织记录：日期、周次、主题、形式（主题班会/事务通知/团队活动/安全教育/心理健康）、主要内容、学生参与情况、效果评估。

#### 2.4.7 班费管理

班费收支流水记录。

**派生计算**：余额 = 收入累计 - 支出累计（按记录顺序滚动计算）

每笔记录包含：日期、收支类型、金额、用途说明、经手人、证明人、备注。

#### 2.4.8 班委管理

记录班级干部信息：职务、姓名、职责描述、任职时间、备注。

#### 2.4.9 班级活动

记录班级活动：日期、活动名称、类型（文体活动/社会实践/志愿服务/学科竞赛/节日庆祝/其他）、参与人数、活动总结、获奖情况、佐证材料。

### 2.5 日志

#### 2.5.1 班主任日志

每日工作日志：日期、星期、天气、主要工作、突发事件、今日反思、待办事项。

#### 2.5.2 工作计划总结

学期工作计划与总结：学期、计划内容、总结内容。

## 3. 个人工作台

### 3.1 健康追踪

集成体重体脂、运动、睡眠三大健康管理维度。

#### 3.1.1 体重体脂追踪

**派生计算：**
- 腰臀比 = 腰围 / 臀围
- 与上周对比 = 本周体重 - 上周体重（自动生成，下拉即可查看趋势）

体重趋势图展示体脂变化曲线，默认标注 120 斤目标线。

#### 3.1.2 运动记录

记录每次运动：日期、运动类型（力量训练/有氧/拉伸/散步/其他）、具体项目、时长、强度、消耗热量、运动感受、是否完成。

#### 3.1.3 睡眠记录

记录每日睡眠：入睡时间、起床时间、睡眠时长、睡眠质量（优/良/一般/差）、起床感受、午休时长。

### 3.2 知识库

基于 Markdown 的笔记管理，与 Obsidian 深度集成。

**功能：**
- `📝 新建笔记` — 输入标题、选择分类和模板后创建空白笔记
- `🔗 打开 Obsidian` — 在本地 Obsidian 中打开知识库

## 4. 数据管理

### 4.1 数据库

所有数据存储在 `workbench.db`（SQLite，WAL 模式），自动创建，无需手动管理。开发模式和打包模式的位置不同：

| 使用方式 | 数据目录 |
|---|---|
| 项目源码启动 | 项目根目录 `data/`、`知识库/` |
| Windows 安装包 | `%LOCALAPPDATA%/MeimeiWorkbench/` |
| macOS 安装包 | `~/Library/Application Support/MeimeiWorkbench/` |

也可以使用 `WORKBENCH_DATA_DIR` 和 `WORKBENCH_KB_DIR` 自定义位置。

### 4.2 派生计算列

以下列由系统在读取时自动计算，**无需手动填写，也不应覆盖**：

| 工作表 | 派生列 | 计算规则 |
|--------|--------|---------|
| 旧版成绩工作表 | 月考1/期中总分、进退步 | 仅用于旧通用工作表兼容；当前成绩页面按考试配置实时计算 |
| 日常行为积分 | 月合计 | W1-W8 之和 |
| 日常行为积分 | 排名 | 按总分降序 |
| 班费管理 | 余额 | 收入累计 - 支出累计 |
| 体重体脂追踪 | 腰臀比 | 腰围 / 臀围 |
| 体重体脂追踪 | 对比上周 | 本周体重 - 上周体重 |

### 4.3 导入导出

- **学生信息导入**：支持 Excel 预览，确认后按学号自动合并去重
- **成绩导入**：支持长表和宽表预览、错误提示、重复记录更新/跳过，以及确认后原子提交
- **通用导出**：所有工作表均支持一键导出为 Excel（`📥 导出Excel` 按钮）
- **汇总报表**：成绩和考勤支持导出专门的汇总报表

### 4.4 备份与恢复

- 首页点击“备份数据”可以创建手动数据库备份。
- “恢复”前系统会自动创建当前数据库的 `pre-restore` 备份。
- 恢复文件必须是本工作台生成的有效 SQLite 数据库；恢复完成后建议重启工作台。
- 升级、迁移和应用内更新前也会自动创建备份。
- 学期归档只会将该学期设为只读，不会删除记录；切换到归档学期后仍可查询和导出。

### 4.5 回收站与操作审计

- 教师工作台左侧“回收站与审计”会显示当前班级和学期中已删除的学生、事件、工作项、关注、沟通、成绩、考勤规则、班级任务、值日和通用工作表记录。
- 点击“恢复”会把记录放回原位置；删除来源记录时同步隐藏的关联工作项也会一起恢复。
- “操作审计”记录操作渠道、操作者、对象、动作、时间和结果。API Key、访问令牌、电话与地址等敏感参数不会以原文写入审计摘要。
- “永久删除”不可恢复，只能在运行工作台的电脑本机操作，并且必须输入“永久删除”完成二次确认。
- 已归档学期不能删除、恢复或永久删除记录；需要先回到仍在进行的学期处理。

### 4.6 手机与平板设备授权

- 只有运行工作台的电脑本机可以生成配对二维码和管理授权设备。
- 二维码 5 分钟有效且只能成功配对一次；复制地址与扫描二维码的效果相同。
- 配对设备默认授权 90 天。电脑端“手机访问”窗口会显示设备状态和最近访问时间，可单独撤权或全部撤权。
- 移动端顶部可以主动退出当前设备。撤权、退出或过期会立即阻止数据接口，并显示重新配对说明。
- 设备凭证不会以原文保存在数据库中；工作台重启不会自动解除现有授权。

## 5. 常见问题

**Q: 启动后浏览器访问被拒绝？**
如果 5000 端口被其他程序占用，程序会自动切换到后续可用端口，并在终端打印实际端口。也可以使用 `python backend/run.py --port 8080` 指定端口。

**Q: 手机扫描二维码打不开？**
请确认手机和平板与电脑连接同一个 Wi-Fi，并在电脑防火墙中允许工作台通过“专用网络”。配对二维码只能使用一次且 5 分钟后失效；出现“需要重新配对”时，请在电脑端重新生成二维码。已经授权的设备在有效期内可跨工作台重启继续使用；被撤权、主动退出或凭证过期后必须重新扫码。

**Q: 为什么安装包会出现安全提示？**
当前 Release 尚未配置 Windows/macOS 代码签名证书。只从 GitHub Release 下载并核对 `SHA256SUMS.txt` 后使用；不要把安装包端口映射到公网。

**Q: 更新按钮提示开发模式不能安装？**
这是正常现象。源码启动只支持检查更新，不会自动替换正在运行的开发目录；需要使用桌面安装包验证更新流程。

**Q: 学生信息导入失败？**
请确保 Excel 表头包含「学号」和「姓名」两列（不带多余空格/换行），缺少学号的行会被跳过。建议先下载标准模板填数据。

**Q: 总分/余额等列显示不对？**
派生列由系统自动计算，请勿在添加记录时手动填入这些列的值。如果已填入错误值，删除对应行后重新添加即可。

**Q: 知识库在哪里？**
知识库文件存储在项目根目录的 `知识库/` 文件夹中。可在工作台内创建笔记，也可直接用 Obsidian 打开该目录（`打开 Obsidian` 按钮）。

**Q: 如何备份数据？**
复制 `data/workbench.db` 文件即可完成全量备份。建议定期备份。

**Q: 数据表中如何搜索？**
部分页面（如考勤管理）的数据表有搜索框，输入关键字后按 Enter 即可过滤。学生信息页面的搜索框按学号或姓名搜索。

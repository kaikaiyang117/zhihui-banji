# 发布检查清单

当前参考版本：`v1.0.4`。该版本三平台安装包和校验文件均已发布，但未配置代码签名证书。

## 自动检查

- [ ] 后端测试全部通过。
- [ ] 前端生产构建通过。
- [ ] 浏览器 UI 冒烟测试通过。
- [ ] 今日工作台的逾期、今天、未来 7 天、规则命中、材料进度和待复查人数与目标列表一致。
- [ ] 今日工作台的本月日历能显示校历特殊安排和待办日期，点击日期能看到当天详情，未来 7 天列表与来源记录一致。
- [ ] 从今日工作台两步内可完成或延期工作项；Escape 关闭弹窗后焦点返回原按钮。
- [ ] 旧版考勤数据升级到结构化表后，日期、学生、状态、原因、到离校时间和备注未丢失，重复启动不重复迁移。
- [ ] 保存考勤自动命中规则且只生成一个工作项；完成后显示已处理，重复检查不重开，条件解除后再次命中会复用并重开原工作项。
- [ ] 考勤学生/月份/周次/场景统计与明细一致，导出明细和汇总可正常打开。
- [ ] 旧数据库升级至 v11 后，旧成绩、考试名称、日期、科目和排名无损回填；重复启动不重复迁移，升级前备份存在且可通过完整性检查。
- [ ] 学期结转只复制成绩科目和异常规则配置，不复制考试、成绩记录、导入批次或规则命中历史。
- [ ] 成绩长表和宽表均先预览再确认；错误行不写入，重复记录的“更新/跳过”数量与提交结果一致，确认提交任一行失效时整批回滚。
- [ ] 缺考、免考和未录入不按 0 分计入平均分；完整人数、科目均值、总分排名、A/B/C 分层、总分/排名变化与固定样本一致。
- [ ] 成绩下降规则重复评估不重复创建工作项；完成后显示已处理，恢复后解除，再次下降复用并重开原工作项，处理结果进入学生时间线。
- [ ] 成绩汇总导出可打开，缺考、免考和未录入保留文字状态；页面和 Agent 只读查询结果使用同一结构化成绩服务。
- [ ] 校历矩阵 Excel 和日期明细 Excel 均能先预览再确认；月份、周次、事项、休息日和调休日期转换正确，冲突不会静默覆盖。
- [ ] 校历管理按当前学期展示完整周次网格，学期起止日期、当前周次、未设置日期和重点安排数量正确；不依赖月份翻页才能查看学期内容。
- [ ] 校历人工修正、当前学期范围外提示和 `school_calendar_query` 网页/微信查询结果一致。
- [ ] 评语模板不支持的变量会被拒绝，缺失变量预览必须二次确认；批量生成不会覆盖人工编辑或已进入审核流程的内容。
- [ ] 评语状态只能按草稿、待审核、完成、已发送规则流转；版本历史、审核交付信息和审计记录完整。
- [ ] 旧版评语工作表按学号稳定迁移且可重复启动；学生详情回溯、打印页和 Excel 导出与当前班级/学期一致。
- [ ] 班会、活动和日志旧通用表迁移可重复执行且保留原始行；班会行动项、活动跟进与统一工作项状态一致。
- [ ] 活动附件写入失败不会留下伪成功记录；日志月历和学生/事件/待办/班会/活动关联可以回到来源。
- [ ] 知识库可站内创建、搜索、编辑和预览 Markdown；外部文件修改时能读取外部内容、采用修改或强制保存，不覆盖未知内容。
- [ ] 报告预览与业务列表统计一致；周报、月报、成长报告和学期档案归档后只读；来源追溯、缺失数据说明和 Excel 导出可用。
- [ ] Agent 固定回归样例通过；网页刷新可恢复会话，会话切换不会串上下文；工具失败只有限重试，错误 JSON 不会生成伪写入。
- [ ] Agent 写工具必须先生成预览；确认、取消、过期、参数绑定、重复确认、越权、备份、失败恢复和审计均通过；微信默认拒绝敏感和高风险写操作。
- [ ] 宽屏工作台和座位表使用侧栏之外的可用宽度；2048/1440px 不出现旧固定最大宽度留白，800/390px 不出现页面级横向溢出，窄屏座位表只在内部横向滚动。
- [ ] 微信逾期/今日工作项提醒按任务和接收人幂等发送，消息只包含必要摘要，并可回到网页处理详情。
- [ ] 个人健康目标、饮食记录、周期汇总、复盘、提醒和 Excel 导出可用；健康数据不会进入班级报告或微信学生查询。
- [ ] 自动化并发检查中的 300 个成绩配置、汇总和规则读取请求全部成功，不出现共享 SQLite 连接错误或班级/学期上下文串用。
- [ ] Electron 冒烟测试通过：窗口标题、手机访问/更新入口、后端生命周期和退出后端口释放。
- [ ] Electron 窗口只加载后端回环地址；外部链接、`obsidian://` 和下载按桌面策略处理，不打开不受控窗口。
- [ ] 安装包内 Node server bundle 的 `app-version.json` 与发布标签一致。
- [ ] 如果配置了 Secrets，正式标签构建已完成 Windows 签名、macOS 签名和公证；未配置时确认 Release 已明确标注“未签名”。
- [ ] Release 中包含两个安装包、`SHA256SUMS.txt` 和 `update-manifest.json`。
- [ ] 应用内更新能从 GitHub Release 下载并完成 SHA-256 校验；私有仓库场景已在更新窗口配置 GitHub Token。

## Windows 实机

- [ ] Windows 10/11 x64 可以安装、启动和卸载；双击打开的是 Electron 窗口而非外部浏览器。
- [ ] 托盘“打开工作台”和“退出工作台”正常；退出后后端进程消失、端口释放、局域网访问失效。
- [ ] 关闭窗口后隐藏到托盘，托盘恢复窗口正常。
- [ ] 安装旧版本后覆盖安装新版本，数据库和知识库仍然存在。
- [ ] 5000 端口被占用时自动切换端口，窗口仍能正常打开。
- [ ] 手机扫描二维码可以访问，关闭程序后局域网访问失效。
- [ ] 二维码只能使用一次且过期后提示重新配对；服务重启后已授权设备仍可访问。
- [ ] 电脑端单设备撤权和全部撤权立即生效，移动端主动退出后需要重新配对。
- [ ] 点击“更新”可以下载、校验、确认安装，并在应用退出后启动安装器完成覆盖安装。

## macOS 实机

- [ ] Apple Silicon 安装包通过 Gatekeeper，Intel 安装包通过 Gatekeeper。
- [ ] 双击打开的是 Electron 工作台窗口，不自动打开浏览器。
- [ ] 托盘和 Dock 行为正常；退出工作台后后端进程和端口释放。
- [ ] 覆盖安装后数据库、备份和知识库仍然存在。
- [ ] macOS 更新助手可以替换 App；新 App 启动失败时能恢复旧 App。
- [ ] 手机扫描二维码可以访问，关闭程序后局域网访问失效。
- [ ] 中文文件名（Excel、备份、迁移包、附件）下载和保存正常。

## 手机和平板

- [ ] iPhone Safari：竖屏、横屏、二维码访问、搜索、弹窗。
- [ ] Android Chrome：竖屏、横屏、二维码访问、搜索、表格横向滚动。
- [ ] iPad Safari：分栏宽度、座位表、数据表和导入预览。
- [ ] Android 平板 Chrome：分栏宽度、座位表、数据表和导入预览。
- [ ] 390px 窄屏：今日行动卡两列排列，工作项操作可点击，底部导航和凯凯入口不遮挡主要内容。
- [ ] 390px 窄屏：考勤日期/场景、五项统计、学生点名、规则状态和统计筛选可用，保存按钮及异常字段不被底部导航遮挡。
- [ ] 390px 窄屏：成绩配置、考试切换、统计表格横向滚动、长宽表导入预览、错误提示和确认按钮均可用且不被底部导航遮挡。

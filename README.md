# 智汇·班记

面向班主任与一线教师的本地班级工作台，帮助教师把学生跟进、教学管理、班级事务、家校沟通和学期总结集中到一个地方完成。

系统以本地数据为基础，适合在 Windows 或 macOS 桌面环境中使用，也支持在可信局域网内通过手机访问。

## 适合谁

- 需要持续跟进学生状态、行为和家校沟通的班主任
- 需要管理课程、考勤、成绩和班级事务的任课教师
- 希望把零散的 Excel、记录和总结整理成可追溯档案的教师

## 功能总览

### 今日工作台

- 查看当前班级、当前学期和当天需要处理的工作
- 管理待办事项、班级任务和学生跟进事项
- 通过工作入口快速进入常用功能
- 查看近期事件、提醒和需要继续处理的记录

### 学生与班级管理

- 维护学生基本信息，支持按学号合并导入，减少重复学生记录
- 记录需要持续关注的学生事项、教育事件和跟进过程
- 管理座位表、小组、宿舍和值日安排
- 保存与学生相关的附件和辅助材料
- 通过回收站和操作记录降低误删风险，方便追溯处理过程

### 教学与日常管理

- 管理高中课程表，按班级、星期和节次查看课程安排
- 记录日常考勤，支持批量处理、备注、统计和后续跟进
- 管理考试与科目配置，导入成绩并查看总分、排名、分层、变化和异常情况
- 使用四川高中“3+1+2”选科结构管理成绩分析
- 记录行为积分，查看积分变化和班级表现
- 管理校历、班会、班级活动和班费
- 通过班主任日志记录每天的工作、沟通和处理结果

### 家校沟通与教育记录

- 保存家校沟通记录、沟通方式、沟通对象和处理结果
- 根据学生事实和已有记录生成家校沟通草稿，教师确认后再使用
- 为家长会、个别谈话等场景准备沟通要点和材料
- 记录教育活动、班会和班级活动，支持补充附件与过程信息
- AI 只负责整理和起草，不会绕过教师自动向家长发送消息

### 评语、报告与学期档案

- 管理学生评语模板、评语事实和评语生成记录
- 根据教师提供的事实生成评语草稿，提醒缺失信息和需要复核的内容
- 生成班级报告、阶段报告和学期总结预览
- 教师审核后保存为档案，并支持导出和后续查阅
- 将一个学期的班级数据整理成可复盘、可提交的教师档案

### 数据导入、导出与恢复

- 提供学生、成绩等常用数据的模板导入和预览校验
- 支持把班级数据导出为 Excel，便于提交、共享或继续加工
- 支持数据库备份与恢复，恢复前自动保留当前数据备份
- 支持生成完整迁移包，包含数据库、附件和知识库文件
- 支持从迁移包恢复到另一台设备；恢复前会自动备份现有数据
- 模型密钥、微信凭证等敏感配置不会写入迁移包

## AI 能力

系统中的 AI 主要用于“整理、分析和起草”，帮助教师减少重复录入，但不替代教师做最终判断。

- **凯凯小兵**：用自然语言查询班级信息、汇总记录、解释数据和生成工作建议
- **对话式 Excel 导入**：识别表格内容、预览导入结果、指出错误，并在教师确认后写入
- **智能评语**：根据教师提供的事实生成评语草稿，提醒缺失信息和需要复核的内容
- **智能报告**：整理班级数据，生成阶段报告、学期总结和档案预览
- **家校沟通辅助**：生成通知、沟通草稿和谈话准备内容

所有会改变数据、发送消息或产生正式档案的操作，都以教师确认和审核为前提。AI 不会自动删除数据、批量修改关键资料，也不会对学生作出纪律、心理或健康结论。

## 数据与隐私

- 业务数据默认保存在本机，使用本地数据库管理
- 知识库以本地 Markdown 文件保存，附件也保存在本地
- Excel 主要用于导入和导出，不作为系统运行时的唯一数据源
- 桌面版默认只在本机提供服务；手机访问仅适用于可信局域网
- “手机访问”使用临时配对和可撤销凭证，不建议把服务暴露到公网
- 数据删除采用回收站和审计记录辅助保护，重要操作应先备份
- 备份和迁移前请确认目标目录，避免把包含学生或家长隐私的数据复制到不安全的位置

## Windows 使用

### 使用已打包安装包

安装后可以从开始菜单或桌面快捷方式启动“智汇·班记”。应用运行时会在 Windows 状态栏托盘中保留入口：

- 左键或菜单中的“打开工作台”用于显示主窗口
- 关闭主窗口通常会隐藏到托盘
- 退出应用请使用托盘菜单中的“退出工作台”
- 首次使用手机访问时，让手机和电脑连接同一个可信局域网

### 从源码启动开发环境

首次使用建议先准备开发依赖：

```powershell
.\scripts\setup-dev.ps1
```

之后可以双击项目根目录的 `启动工作台.bat`。该入口会构建必要的前端和服务端产物，并启动开发工作台；前端开发模式支持热更新，修改页面后通常不需要重新安装桌面程序。

也可以分别启动前端开发服务和桌面开发服务：

```powershell
cd frontend
npm run dev
```

另开 PowerShell 窗口：

```powershell
cd desktop
npm run dev
```

## 构建 Windows 安装包

在 Windows PowerShell 中运行，或直接双击项目根目录的打包脚本：

```powershell
.\打包Windows安装包.bat
```

需要指定版本或运行 Electron 冒烟测试时：

```powershell
.\打包Windows安装包.bat 2.3.9 -RunSmokeTest
```

构建完成后，安装包输出到：

```text
artifacts/Zhihui-Banji-Setup-Windows-x64.exe
```

如需了解签名、证书、构建参数和故障排查，请查看 [Windows 打包说明](packaging/README.md)。

```text

知识库/         本地知识库 Markdown 文件
```

## 当前产品边界

- 当前主导航聚焦教师工作台，不再展示“个人工作台”入口和页面
- 历史数据库、知识库文件和相关本地数据仍保留，用于兼容已有数据和迁移恢复
- 系统重点覆盖班级管理、教学管理、家校沟通、教育记录和学期档案
- 作业布置与收缴、监考排班、教学进度等能力暂不属于当前核心功能范围
